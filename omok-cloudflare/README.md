# 던바튼 오목 2.7

15×15 자유룰, 5개 이상 연속이면 승리하며 금수는 없습니다.
기존 캐릭터 이미지, Worker 이름, GAME_ROOM 바인딩과 운영 설정을 유지합니다.

## 배포

이 저장소는 Cloudflare Workers Builds와 연결되어 있습니다.
프로젝트 루트는 `omok-cloudflare`이며 `npm run deploy`로 배포합니다.
GitHub Actions는 테스트와 dry-run 검사만 수행합니다. 별도의 배포 비밀키가 필요하지 않습니다.
이전 압축 자동해제 워크플로는 최신 소스를 덮어쓰지 않도록 검사 작업으로 교체했습니다.
기존 ZIP 파일은 이전 버전 보관용입니다.

## 로컬 확인

이 폴더에서 `npm ci`, `npm test`, `npm run build`, `npm run dev` 순서로 실행합니다.

## 변경 사항

- 접속 소켓에 연결된 사용자만 착수할 수 있으며 상대 ID 사칭을 차단합니다.
- 판 상태 저장, 같은 탭의 새로고침 및 자동 재접속을 지원합니다.
- 상대 연결이 끊기면 판을 유지하고 착수를 잠시 중단합니다.
- 무승부, 종료 후 양측 재대전 동의, 선공 교대를 지원합니다.
- 닉네임을 안전한 텍스트로 표시하고 모바일 판 정렬, 마지막 착수 표시, 초대 링크 복사를 추가했습니다.

두 기기나 별도 브라우저에서 접속하세요. 상대가 영구적으로 떠났으면 로비로 나가 새 방을 만드세요.
2.4의 메모리에만 있던 기존 판은 업데이트 시 복구할 수 없습니다.
서버 단위 테스트는 저장 및 소켓 모형을 사용하므로 실제 기기 대전을 대신하지 않습니다.

## 빠른 대전

닉네임 입력 후 빠른 대전을 누르면 다른 대기자와 자동으로 같은 방에 입장합니다.
대기 취소, 중복 접속 대기 방지, 연결 종료 및 30초 이상 응답 없는 대기자 제외를 지원합니다.
기존 GameRoom 바인딩에 별도의 대기실 객체를 사용하므로 새 Durable Object migration이 필요 없습니다.
